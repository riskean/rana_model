# Licensing Notes v001

This project must distinguish technical suitability from usage rights.

## Current baseline

The planned baseline uses:
- FLUX.1-dev
- PuLID-FLUX-v0.9.1
- InsightFace-related face analysis in the upstream PuLID implementation

The FLUX.1-dev model card currently identifies the model as being under the FLUX.1-dev Non-Commercial License. The upstream PuLID FLUX documentation states that use of PuLID with FLUX.1-dev follows the FLUX.1-dev model license.

Therefore this baseline must NOT be treated as commercially cleared merely because the code or repository is public.

## Project rule

Before any public monetized deployment, client work, paid service, or commercial distribution is planned:
1. review the current FLUX.1-dev license terms;
2. review the current PuLID model/asset terms;
3. review the face-analysis model terms actually used;
4. record the approved commercial/non-commercial status in a new project version;
5. if commercial use is required, select a legally compatible model/identity-conditioning stack before deployment.

Technical tests may proceed separately from licensing clearance.

## Privacy

Personal source photos, derived face crops, masks, embeddings, and generated personal images must remain private unless the owner explicitly chooses otherwise.
